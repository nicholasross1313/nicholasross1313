# Public Automation Demos

This folder contains public demonstration projects built specifically for my portfolio.

**Important:** all code, names, workflows and datasets in these demos are original portfolio material. The sample data is synthetic and does not come from my employer, clients or production systems.

The projects are designed to show the way I approach business-side automation:

- automate repeatable logic
- keep exceptions visible
- avoid unnecessary system changes
- prefer local or rule-based processing when possible
- keep human judgement where it matters

## Projects

### 1. Multi-File Reconciliation
A VBA example that reconciles three operational datasets and produces one exception-focused result table.

[Open project](./multi-file-reconciliation/)

### 2. Local Document Batch Processor
A browser-based JavaScript demo that validates document names, identifies duplicates and missing document pairs, and produces a rename mapping. Processing stays in the browser.

[Open project](./document-batch-processor/)

### 3. Browser Workflow Automation
A JavaScript/HTML demo of repetitive browser automation with input validation, asynchronous waiting, retry logic and execution logs.

[Open project](./browser-workflow-automation/)

## Why these are demos

The goal is to demonstrate transferable automation patterns without exposing confidential business logic, private systems, customer information, internal URLs, selectors or production data.
